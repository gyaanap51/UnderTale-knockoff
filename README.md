# Hollow Orbit
A no-combat deep-space puzzle RPG (HTML5, about 15 minutes). Open `index.html` to play.

## Put it online
Netlify Drop (app.netlify.com/drop): drag this folder, get a link. Or GitHub Pages / itch.io.
Open the link in a private window to confirm judges can play without logging in.

## Before you submit
1. Play every chapter and ending. 2. Customize story, names and art so it is truly yours.
3. Finish `docs/DOCUMENTATION.md` in your own words. 4. Check your state's deadlines and AI-use rules.
